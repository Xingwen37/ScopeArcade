# 验证范围

本文件区分既有硬件能力、当前应用测试和未实测环境，避免把源码测试当作新电脑实测。

## 已有硬件基础

通用矢量固件在 Tang Mega138K / AD9767 / DHO4404 / SDG1032X 上通过1Mbaud CRC帧传输、双缓冲和同步消隐验证。固件已在用户板Flash中完成写入、独立读回校验及断电自启动测试。相关游戏模型此前分别通过碰撞、计分、完整比赛和绘图范围测试。

## 应用测试

- 协议CRC、坐标范围和72线段上限。
- 三个内置游戏的独立命名空间、运行和切换。
- 游戏模板导入、重复ID拒绝、目录穿越拒绝。
- 仪器型号不符时不写入，输出先关闭，XY启用后再设置Z，参数回读错误被拒绝。
- 停止后重新启动串口流的确认等待窗口。
- `--self-test`：不访问串口/VISA，验证Tk、三个游戏、模板导入和启动/停止。写入所选数据目录中的自检结果。

源码测试使用Python3.13.5与3.13.7；发布包使用标准CPython3.13.7、pySerial3.5、PyVISA1.16.2、PyInstaller6.22.3。

2026-09-20在Windows11 x64（10.0.26200）完成：8项单元测试、源码/EXE离线自检、含中文和空格的新目录迁移自检。实际EXE通过界面按钮完成DHO4404/SDG1032X配置与串口握手，赛车→Pong→小恐龙即时切换，空格操作Pong，导入并运行示例游戏，断开后实测发生器CH1为OFF。运行时约60次/秒；所有游戏共用Flash中的通用绘图器，未重写FPGA。实机驱动测试中每个游戏连续发送90帧，收到持续确认，跨切换边界的确认可能在下一窗口到达；不将单个统计窗口当作严格丢帧计数。停止1.6秒后重新发送也通过。

## 限制

仅支持这两款已验证仪器型号；不声明其他型号兼容。Windows10/11 x64为目标平台，但没有实测过的第二台电脑不能宣称已验证。需要系统VISA和串口驱动；应用不会安装或改写驱动、FPGA Flash及调试器固件。外部游戏是可信Python代码，不是沙箱。
